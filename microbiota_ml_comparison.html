PD 的人數最多，AD 與 T2D 的協變量最齊。 PD 是 223 對 137 的獨立糞便、16S V3–V4，但公開表沒有年齡與性別，而且福岡只有 5 名對照，基準模型一定要放採樣地。AD 是 43 對 43、年齡與性別配平，再加「是否大坪醫院」。T2D 是 100 人、聽力受損 43 對 57。三邊都用 genus CLR 的 elastic-net。菌相模型的 AUROC 與 AUPRC 要高於「只用協變量」和「只用 Shannon、豐富度」。

共同流程（每一個研究各做一次）

  1. 用 run 把 count 表接到 metadata。保留 count，自己做過濾與轉換；若只有相對豐度，就不要再稀釋一次。
  2. 去掉明顯失敗的文庫後，以盛行率過濾 taxon（例如至少 10% 樣本出現）。這個門檻只用訓練折的樣本來算。
  3. 主矩陣用 genus 的 CLR（加一個小偽計數）。另外做一版相對豐度、一版有無（presence/absence），看交叉驗證哪一版穩。
  4. 先畫 PCoA 或 Aitchison 距離，並用 PERMANOVA 看 group、性別、年齡、部位、log(spots)。深度若能分開兩組，分類分數要對著深度基準來讀。
  5. Elastic-net logistic 當主模型。Random forest 或淺層 gradient boosting 當對照。sPLS-DA 適合做出可報告的菌屬面板。係數與 SHAP 用來解釋，不用來取代留出集的 AUROC。
  6. 指標用 AUROC、AUPRC、balanced accuracy，並做標籤置換。IBD 不要只報 accuracy，因為永遠猜 IBD 就有 74%。
  7. 差異豐度（ALDEx2、ANCOM-BC 或 MaAsLin2）用來核對分類器挑中的菌是不是同一批。那是關聯，不是預測成績。
  8. 每個研究只有一個 BioProject，沒有外部驗證集。內部交叉驗證會偏樂觀，報告時寫成內部估計。

模型怎麼選

做法在這五份資料的角色
Elastic-net logistic預設主模型。n 小、p 大、需要一組可解釋菌屬。
只用協變量的 logistic基準。菌相模型要贏過它。
Shannon + 豐富度第二基準。若打平，訊號是整體多樣性。
Random forest看非線性。重要性在組成型資料上較不穩。
sPLS-DA菌相研究常用的低維面板，適合跟 elastic-net 對照。
Gradient boosting樹要很淺，且用巢狀 CV 調參，否則 n=77–100 容易過擬合。
神經網路、深度學習這五份的樣本數不夠。
未分組的隨機切分（CRC）同一人的腫瘤與鄰近組織會漏到測試集，分數會虛高。

各研究再加的協變量

  • PD：採樣地、log(spots)。公開表沒有年齡、性別、BMI 或用藥。
  • AD：年齡、性別、log(spots)、是否大坪醫院。沒有認知分數可預測。
  • T2D：年齡、性別、log(spots)。論文裡的細胞激素不在 metadata。
  • IBD：沒有年齡與性別，也沒有 CD/UC。至少放入 log(spots)，並分別報告含與不含那 5 個 spots < 1,000 文庫的成績。
  • CRC 組織：性別、年齡、部位、BMI、log(spots)，以及依病人分組。期別模型只用 45 列腫瘤。
  • CRC 糞便：可描述這 23 人的糞便群落、或和同一人的黏膜比較。它回答不了「健康人 vs 大腸癌」。
